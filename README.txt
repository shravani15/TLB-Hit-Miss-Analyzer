TLB HIT/MISS SIMULATOR (basic web version)

HOW TO RUN
1. Unzip this folder.
2. Double-click index.html. It opens in your browser. No internet or install needed.

HOW TO USE
- Set TLB entries, page size, replacement policy (LRU / FIFO / Optimal) and access times.
- Type virtual addresses (decimal or 0x hex) or click a preset.
- Press Step, Play or Run all to watch each reference become a TLB hit or miss.
